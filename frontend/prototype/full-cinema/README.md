# Полный локальный прототип

Открыть: http://127.0.0.1:5174/prototype/full-cinema/

1. Ввести имя и создать комнату. По умолчанию: оригинальный режим, 10 очков, скрытые оценки и повтор рангов выключены.
2. Открыть «Тест-панель» внизу слева и добавить участников (до 15 ботов).
3. В фойе выбрать режим и параметры. Настройки панели применяются кнопкой; обычные настройки фойе также работают.
4. Для каждого бота выбрать случайную последовательность, повтор оценок ведущего, обратную последовательность или ручные S–D. Отключение автоотправки позволяет отправлять ответы кнопкой. Задержка задаётся отдельно.
5. Начать игру: дверь → зал → спиральный портал → полотно игры. На телефоне используется обычное меню без интерьерного прохода.

Ручные оценки доступны после появления пяти произведений. При запрете повторов выбор занятого ранга меняет два ранга местами. Изменение стратегии не переписывает уже сохранённый ответ: для новой попытки можно сбросить раунд в фойе.

В оригинальном режиме все готовые участники переводят сцену в зелёный; раскрытие запускает хост. «Мнение одного» сохраняет отдельные фазы критика и угадывания. Если бот-критик настроен копировать ведущего, который ещё не может оценивать, сменить ему стратегию на случайную или ручную — причина отображается в панели.

Для быстрой проверки пьедестала можно поставить цель 1 очко. Для полного теста оставить 10. После итоговой таблицы «Новая игра» возвращает тех же участников в фойе. Кнопка сброса в панели требует подтверждения и также сохраняет участников/настройки.

В «Мнении одного» готовность отмечается после сохранения: пять выбранных рангов ещё не означают готовый ответ. «Изменить оценки» снимает галочку. В объявлении показаны текущий критик и его персонаж (кроме скрытого режима); красная роль критика и зелёная роль угадывающего. Угаданные фильмы подсвечиваются зелёным, ошибки красным; при пяти попаданиях зелёное свечение сменяется золотым, имена угадавших выделены золотом. Номер текущего круга указан сверху; естественный цикл очереди проверен на трёх кругах по четыре участника.

Выход из игры в фойе проигрывает обратный путь камеры от полотна через двери. Выход в главное меню из любой сцены показывает только возврат от кассы к фасаду с закрытием наружных створок. Обратные проходы имеют мягкое ускорение и торможение. Escape пропускает переход. На телефоне и при reduced motion применяется короткий переход. Афиши фасада прикрыты стеклом с каплями и локальным преломлением; они по-прежнему выбираются один раз при загрузке страницы.

Это изолированная игра в одной вкладке: код и приглашение демонстрационные, сетевые игроки не подключаются. Перезагрузка сбрасывает матч и ботов, а также выбирает новые афиши. Production не используется. Каталог общий; публичные афиши обслуживает существующий локальный poster-service на :3001.

Проверки модели: `node --test frontend/prototype/full-cinema/full-model.test.js` из корня проекта. Для сборки использовать scoped Vite build этого index.html, а не корневой npm run build.
