# Локальный каталог OVERRATED

Приложение читает `movies.json` при запуске. Для игры не требуется TMDB API key: ключ используется только отдельным импортом. Постеры проходят через существующий серверный прокси и кеш.

## Обновление

1. Извлечь только названия из исходного XLSX: `python backend/extract-catalog.py <файл.xlsx>` (openpyxl, только инструмент разработки).
2. Задать `TMDB_API_KEY` в корневом `.env` и запустить `node backend/import-catalog.cjs`.
3. Проверить `.state/catalog-candidate.json` и `.state/catalog-pending.json`. Импорт сам не заменяет рабочий `movies.json`.
4. После проверки заменить локальный каталог кандидатом и выполнить `npm test`, lint и сборку frontend. Публикация — отдельный шаг.

Кеш ответов, исходные названия и резервная копия старой базы находятся в игнорируемой `.state`. В репозитории нет ключа, полного Excel, ников или ссылок на записи стримов. Старые `fetch_all_movies.js` и `update_posters_tmdb.js` не использовать для этого каталога: они не знают о новых категориях.

## Правила

- Фильмы, в том числе аниме-фильмы и полнометражные мультфильмы → `films`.
- Японские анимационные сериалы → `anime`, прочие анимационные сериалы → `cartoons`; игровые → `series`.
- Сезоны и эпизоды объединяются по TMDB TV ID; отдельные полнометражные фильмы остаются отдельными записями.
- Дополнительные сериалы: TMDB ≥7,0 и ≥500 голосов, до трёх страниц популярного в каждом направлении. Происхождение TR/IN исключается, кроме просмотренного на стриме. Это ограниченная подборка, не полный каталог всех сериалов с рейтингом ≥7.
- Выбор в смешанном режиме равномерный по произведениям общего пула, без квот по категориям.
- Русский постер выбирается из изображений конкретного ID: приоритет основному постеру, затем числу голосов, оценке и разрешению. Если русского нет — основной TMDB-постер. Принадлежность проверена автоматически, художественная узнаваемость всех вариантов вручную не оценивалась.
- Годы и завершённость — снимок метаданных TMDB на момент импорта. Продолжающиеся сериалы имеют `...`; обновление статуса потребует повторной сверки. У разных каталогов возможны расхождения года фестивальной/прокатной премьеры.
- Неоднозначные названия уточняются в `catalog-overrides.json`. Импорт не выбирает первый результат без проверки. Повреждённые и adult-метаданные исключаются.
