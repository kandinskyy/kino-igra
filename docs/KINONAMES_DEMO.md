# Kinonames: управляемый локальный просмотр

Запуск: из `frontend` выполнить `node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5174 --strictPort`.

- Ведущий: http://127.0.0.1:5174/prototype/kinonames-demo/?view=leader
- Игрок: http://127.0.0.1:5174/prototype/kinonames-demo/?view=player

Обе вкладки используют одну демонстрационную партию: многопользовательская разновидность, 3 против 3, без предателей, по 60 секунд на подсказку и угадывание. Роли и разновидность в этом просмотре закреплены. Подсказки ботов демонстрационные, не интеллектуальный подбор ассоциаций.

Внизу: к началу, назад, продолжить/пауза, следующий шаг, к финалу, +1/+5 секунд, разрешить звук и ползунок выбора шага. Пауза останавливает и ботов, и виртуальные часы. Шаги восстанавливают поле, голоса, таймер и итог. Можно также самому отправить подсказку ведущим либо проголосовать игроком; будущие шаги перестроятся из нового состояния. Новая партия генерирует новое поле.

Чтобы посмотреть вход, начните с главного меню, введите имя и создайте комнату. После входа в фойе нажмите «Начать игру». Для второго ракурса откройте ссылку игрока. Сброс с любой страницы действует на обе. Включите звук отдельным нажатием в каждой вкладке; скрытые вкладки не воспроизводят сигналы. Сигнал начала фазы и быстрые щелчки последних пяти секунд используют существующий WebAudio-контекст. На паузе щелчки не идут; обратная перемотка не повторяет старые сигналы начала.

Это dev-only адаптер на существующем серверном движке Kinonames, а не новая production-система комнат. Endpoint `/__kinonames-demo` подключается только Vite dev plugin; в production-сборке отсутствует. Обычному игроку не передаются цвета закрытых карточек во время партии. Обратный просмотр/доступ к роли ведущего предназначены только для локальной тестовой панели. Чат и управление составами здесь не имитируют настоящую сетевую игру; её транспорт остаётся отдельным существующим подключением приложения.

Проверено 2026-11-13: 17 тестов игрового движка + 3 теста сценария; тест WebAudio, включая щелчки и приостановленный контекст; HTTP-защита dev endpoint и отсутствие скрытых цветов в player snapshot. Browser: создание комнаты, фойе, запуск и переход, цветная карта ведущего, закрытая карта игрока, голоса, подтверждение, финал. Scoped Oxlint: одна предупреждающая рекомендация о синхронизации presentation gate через effect; production Vite build успешен, прежнее предупреждение о размере chunks. Звук проверен на уровне WebAudio и успешного разрешения браузером; фактическая громкость на устройстве пользователя не оценивалась.

## Обновление прототипа — 2026-11-13

Предыдущие ограничения закреплённых ролей/одной разновидности выше исторические. Теперь сворачиваемая «Тест-панель» поддерживает competitive (3×3), coop и traitors (4×4), ручные шаги, паузу, перемотку и виртуальные часы. После финала новая партия генерирует скрытое поле, перемешивает роли и ждёт готовности. Обычная «Новая партия» доступна только host, у игрока неактивна. Отдельная «Новая партия (тест)» управляет исключительно локальным сценарием, не production-правами.

На поле убраны заголовочная и голосовательная плашки, основной таймер сохранён. Полоса подтверждения расположена на выбранной карточке. Аватарки снизу и не перекрывают имя, нейтральные карты серее. Исправлен presentation gate и переход главная→фойе.

Проверки: полный Node72/72; legacy model/journey/audio10/10; scoped Oxlint clean; production Vite build PASS с прежним предупреждением крупных chunks. Браузер: вход/фойе/портал, голоса, подтверждение, финалы трёх вариантов, host-only restart в двух вкладках. Последний перенос аватарок проверен при фактической ширине около1017px; viewport override IAB не применился, повторная мобильная проверка остаётся. Фактическая громкость устройства не оценивалась. Каталог819 и production не менялись.

Исправление кнопки смены роли: перенесена внутрь flex-плашки подсказки, убрано наложение отрицательным margin. Browser: кнопка полностью внутри, отступы сверху/снизу по9px. Scoped Oxlint PASS.
